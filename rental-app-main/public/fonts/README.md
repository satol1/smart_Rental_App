# Onest

Self-hosted Latin and Cyrillic variable WOFF2 subsets, weights 100–900.
Source: `@fontsource-variable/onest@5.2.6`, https://fontsource.org/fonts/onest
Distributed under the SIL Open Font License; see `OFL-Onest.txt`.

The interface uses these local assets with `font-display: swap`; no font service
request is needed at runtime.
