# 🔐 Руководство по безопасности

## Обзор реализованных мер безопасности

### ✅ Критические исправления (завершены)

#### 1. Усиление секретных ключей
- **Скрипт генерации**: `scripts/generate_secrets.py`
- **Валидация**: Минимум 32 символа, 16 уникальных символов
- **Проверка дефолтных значений**: Блокировка запуска с дефолтными ключами
- **Использование**: `python scripts/generate_secrets.py`

#### 2. Настройка HTTPS
- **Nginx конфигурация**: Обновлена с современными SSL настройками
- **HSTS**: Включен с `max-age=31536000; includeSubDomains`
- **Дополнительные заголовки**: CORS, COEP, COOP, CORP
- **Редирект**: Автоматический редирект с HTTP на HTTPS

#### 3. Усиление политики паролей
- **Минимальная длина**: 8 символов (настраивается)
- **Требования к сложности**: Заглавные, строчные, цифры
- **Проверка на простые пароли**: Блокировка распространенных паролей
- **Валидация повторяющихся символов**: Максимум 50% повторений

### ✅ Высокие приоритеты (завершены)

#### 4. Система аудита безопасности
- **Модель**: `SecurityAuditLog` с полным логированием
- **События**: Попытки входа, подозрительная активность, доступ к данным
- **API**: `/api/admin/security/audit/*` для администрирования
- **Индексы**: Оптимизированы для быстрого поиска

#### 5. Защита от брутфорса
- **Лимит попыток**: 5 неудачных попыток за 15 минут
- **Блокировка IP**: 60 минут после превышения лимита
- **Whitelist**: Доверенные IP адреса
- **API управления**: Разблокировка, статистика, очистка

### 🔄 Средние приоритеты (в процессе)

#### 6. Улучшение CSP политики
- **Текущее состояние**: Убрано `unsafe-inline` из script-src
- **Добавлено**: `strict-dynamic`, nonces, дополнительные директивы
- **Статус**: Требует тестирования с фронтендом

## 🛠️ Инструкции по настройке

## 📊 Мониторинг безопасности

### API эндпоинты для админов

- `GET /api/admin/security/audit/logs` - Логи безопасности
- `GET /api/admin/security/audit/stats` - Статистика событий
- `GET /api/admin/security/brute-force/blocked-ips` - Заблокированные IP
- `POST /api/admin/security/brute-force/unblock/{ip}` - Разблокировка IP
- `GET /api/admin/security/health` - Состояние системы безопасности

### Типы событий безопасности

- `login_success` / `login_failed` - Попытки входа
- `brute_force_attempt` - Попытки брутфорса
- `suspicious_activity` - Подозрительная активность
- `data_access` - Доступ к данным

### Уровни серьезности

- `low` - Обычные события (успешные входы, доступ к данным)
- `medium` - Неудачные попытки входа
- `high` - Подозрительная активность
- `critical` - Брутфорс атаки, попытки обхода защиты

## 🔧 Конфигурация

### Настройки паролей (config/core.py)

```python
PASSWORD_MIN_LENGTH: int = 8
PASSWORD_REQUIRE_UPPERCASE: bool = True
PASSWORD_REQUIRE_LOWERCASE: bool = True
PASSWORD_REQUIRE_DIGITS: bool = True
```

### Настройки защиты от брутфорса

```python
max_attempts = 5  # Максимум попыток
window_minutes = 15  # Окно времени
block_duration_minutes = 60  # Длительность блокировки
```

### CSP политика

```nginx
Content-Security-Policy: default-src 'self'; script-src 'self' 'strict-dynamic' 'nonce-{nonce}'; style-src 'self' 'unsafe-inline'; object-src 'none'; frame-ancestors 'none'; img-src 'self' data: https:; font-src 'self' data:; connect-src 'self'; form-action 'self'; base-uri 'self';
```
