# План реализации

## Направление

Рабочий инструмент для съёмки с характером аккуратно оформленного каталога фототехники: тёплая светлая основа, глубокая серая типографика, фирменный синий для действия, шалфейные и песочные поверхности только по смыслу. Полноценная кириллица, явные иерархия и интервалы, фотографии оборудования как основной визуальный материал.

## Архитектура

Токены в централизованном CSS и Tailwind; существующие ui/ примитивы, единая шкала движения. Обновление общего каркаса и всех повторяемых паттернов распространяется на рабочие страницы. Каталог и бронирование получают целевую переработку композиции. Комплекты извлекаются существующими сервисами, без новых backend-контрактов.

## Проверка

Снимки до/после на desktop и mobile; каталог, календарь, авторизация, диалоги, личные и административные экраны при доступных данных. Реальные локальные данные используются по возможности; тестовые сценарии с имитацией API явно обозначаются. Vitest, eslint, TypeScript и production build. Независимое визуальное и функциональное ревью, затем исправление его существенных замечаний.

## Complexity Tracking

Новые runtime-библиотеки не требуются. Допускается самостоятельный локальный шрифтовой ресурс с кириллицей. Не добавляются альтернативный календарный движок, параллельный набор компонентов или новые расчёты бронирования.
